📌 Visão Geral do Projeto

Este projeto simula uma consultoria de dados para a área de Recursos Humanos, utilizando o dataset IBM HR Analytics para identificar padrões de rotatividade (turnover) e gerar insights estratégicos para retenção de talentos.

**A análise percorre todo o fluxo profissional de dados:**

Extração → Tratamento → Análise Exploratória → Modelagem → Dashboard → Insights
🏢 Problema de Negócio

Empresas enfrentam desafios como:

🔺 Alta taxa de turnover

📉 Baixa retenção de talentos

❓ Falta de clareza sobre fatores de desligamento

📊 Decisões baseadas apenas em percepção
